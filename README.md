# Лабораторная работа №3

**Тема:** Футуролог и концепт-художник  
**Автор:** Невзоров Артем  

## Выполненные требования
* **Flexbox:**
  * Прилипающее меню навигации (position: sticky; display: flex).
  * 4 карточки «Технологии будущего» (<article>) с сеткой 4 → 2 → 1 (десктоп / планшет / мобильный).
* **CSS Grid:**
  * Дашборд «Прогнозы по сферам» с сеткой 3 → 2 → 1 колонка.
  * Выделение ключевых слов тегами <strong>, <em>, <mark>.
* **Адаптивность и доступность:**
  * Медиа-запросы (992px и 600px).
  * Горизонтальный скролл отсутствует (box-sizing: border-box).
  * Контрастность текста к фону ≥ 4.5:1.

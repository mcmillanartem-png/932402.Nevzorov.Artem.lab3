## Реализованный функционал
- **Ввод/вывод:** `prompt()` для имени, `alert()` с приветствием и итоговой статистикой, `console.log()` для аналитики.
- **Массив данных:** `[18, 55, 4, 32, 5, 24]` (% годового роста).
- **Функции обработки:**
  - `findMax(arr)` — поиск максимума (с проверкой на > 50%).
  - `calculateSum(arr)` — подсчёт суммы и среднего значения.
  - `filterHighGrowth(arr)` — фильтрация значений > 20%.
  - `analyzeLowGrowth(arr)` — подсчёт количества и доли значений ≤ 5%.
